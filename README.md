# noExit — 방탈출 카페 예약 서비스

방탈출 카페를 검색하고, 파티를 모아 예약하고, 매장이 출석을 관리하는 웹 서비스입니다.
팀 최종 프로젝트이며 제가 맡은 파트와 이후 진행한 뷰 전환 작업을 진행하였습니다.

---

## 사용 기술

- **Backend** : Java 21, Spring Boot 3.5, MyBatis
- **Database** : Oracle (ojdbc11), PL/SQL 프로시저·함수
- **View** : JSP + JSTL → Thymeleaf 로 전환 진행
- **기타** : Spring Boot Mail, Lombok, Gradle

---

## 제가 맡은 기능

팀 프로젝트에서 아래 기능의 백엔드/화면을 직접 구현했습니다.

### 1. 로그인 / 인증
- 세션 기반 로그인·로그아웃, 로그인 상태에 따른 접근 제어
- 로그인 시 사용자 역할(role)을 세션에 담아, 화면·기능별 권한 분기의 기준으로 사용

### 2. 테마 등록
- 사장이 자기 카페의 방탈출 테마를 등록/수정
- 카페 선택 → 장르·난이도·공포도·활동성·소요시간·가격·성인 여부·포스터 이미지 입력
- 등록/수정을 하나의 폼(mode)으로 처리

### 3. 카페 등록
- 사업자 정보·주소·연락처를 받아 카페를 등록
- 등록/삭제(숨김) 흐름 처리

### 4. 출석 체크
- 예약 시간에 온 손님을 매장이 크루 단위로 출석 처리
- **임시저장(세션 누적) → 최종 확정(DB 반영)** 2단계 구조
  - 크루별 출석/노쇼를 세션에 모아두었다가, 확정 시 한 번에 저장
  - 확정 처리는 여러 테이블 INSERT가 얽혀 있어 `@Transactional`로 원자성 보장
  - 노쇼 처리 시 해당 사용자의 매너온도 차감

### 5. 매니저 권한 관리
- 사장이 자기 카페의 매니저 계정을 등록/비활성화
- 등록된 매니저는 사장 일부 기능(예약·출석 관리)에 접근 가능하도록 권한 부여

## 추가로 진행한 작업 — JSP → Thymeleaf 전환

프로젝트를 더 깊이 이해하기 위해, 팀에서 JSP로 작성된 뷰를 Thymeleaf로 점진적으로 전환했습니다.
제가 구현한 화면뿐 아니라 팀원들이 만든 화면까지 전환하면서, **요청 → 컨트롤러 → 서비스 → 매퍼 → DB → 화면** 전체 흐름을 읽고 이해하는 과정을 거쳤습니다.

### 전환 방식
- JSP 뷰 엔진과 Thymeleaf 뷰 엔진을 공존시키고, Thymeleaf를 우선순위로 두어 .html이 있으면 그것을 렌더하도록 구성
- 화면을 한 개씩 전환하며 JSP와 병행 운영
- 전환한 화면은 실제로 앱을 띄워 정상 동작 확인

### 전환하며 정리한 것
- `<%@ include %>` → **fragment**(`th:replace`)로 공통 헤더/사이드바/푸터를 분리해 재사용
- 자바에서 HTML 문자열로 그리던 페이징을, 계산(숫자)만 서버가 하고 화면(`th:each`)이 그리도록 분리
- JSTL(`<c:forEach>`, `<c:if>`, `fmt:`) → Thymeleaf 문법 1:1 대응
- JS 안에서 서버 값이 필요한 경우 `th:inline` 처리

## 코드를 리뷰하며 정리한 개선점

전환 과정에서 팀 코드를 읽으며 개선 여지를 함께 기록


- **동시성** : 중복 신청/승인을 자바 `COUNT` 체크로만 막는 부분은 확인~INSERT 사이에 TOCTOU가 발생할 수 있어, `UNIQUE` 제약으로 DB 레벨에서 최종 방어하는 것을 제안
- **계층 분리** : 인가·상태 검증이 컨트롤러에 있는 경우가 있어, 재사용·테스트에 유리하도록 서비스 계층으로 옮기는 방향을 정리 (일부는 실제로 컨트롤러 → 서비스로 리팩터링)
- **SQL 보안** : 동적 정렬/검색에서 `${}`로 값을 끼워 넣는 부분은 SQL Injection 위험이 있어, 화이트리스트 검증이 필요함을 확인 (컬럼명은 `#{}` 바인딩이 불가한 점도 함께 정리)
- **페이징 방식** : ROWNUM 서브쿼리 중 OFFSET FETCH로 통일

## 실행 방법

```bash
# 1. Oracle DB 준비 후 계정/스키마 설정
# 2. 환경 값 설정 (DB 접속 정보는 환경변수로 분리 권장)
# 3. 실행
./gradlew bootRun
# http://localhost:8080
```

## 프로젝트 구조

```
src/main/java/com/noexit/app
├── controller   요청/응답 처리
├── service      비즈니스 로직 (인터페이스 + 구현 분리)
├── mapper       MyBatis 매퍼 인터페이스
├── model        DTO/VO
├── config, interceptor, common

src/main/resources
├── mybatis/mapper   매퍼 XML (SQL)
├── templates        Thymeleaf 뷰 (전환 완료 화면)
└── sql              테이블/프로시저/함수 스크립트

src/main/webapp/WEB-INF/views   JSP 뷰 (전환 전 원본, 공존)
```
